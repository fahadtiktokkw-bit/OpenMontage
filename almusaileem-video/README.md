# مصنع فيديوهات المسيليم المجاني

MoneyPrinterTurbo: 3 صور، 15 ثانية، 1080×1920، خط تجوال.

## تشغيل فيديو جديد

1. افتح Actions في OpenMontage ثم Almusaileem free video ثم Run workflow.
2. أدخل الموضوع والنص. ترك الحقول فارغة يستخدم مثال المايكروسمنت الحالي.
3. أدخل 3 روابط صور HTTPS، وافصل بينها بعلامة |. كذلك العناوين والتفاصيل: 3 نصوص قصيرة تفصل بينها |.
4. للصوت الطبيعي المجاني ضع رابط تسجيلك في audio_url. يتم اختيار uploaded تلقائياً عند وجود الرابط. التسجيل لا يتجاوز 18 ثانية، والأفضل 15 ثانية. بدون تسجيل اختر silent، أو edge لتجربة الصوت الآلي المجاني.
5. اترك gallery مفعلاً لإضافة النتيجة إلى معرض الموقع. اضبط illustrative=false فقط عند استخدام صور تنفيذ حقيقية.
6. بعد النجاح تحصل على رابط MP4 ثابت وصورة غلاف وتقرير وembed.html للتضمين في مقال.

المعرض المنشور: https://www.almusailem.online/p/blog-page_13.html?lang=ar
يقرأ published/index.json تلقائياً. قد يحتاج تحديث الروابط بضع دقائق بسبب التخزين المؤقت.
الإضافة إلى المعرض تلقائية؛ تضمين فيديو في مقال محدد خطوة منفصلة.

## الصوت ونتيجة الاختبار

نجح تشغيل GitHub الأول وإنتاج فيديو 15 ثانية. رفض Edge الاتصال بخطأ 403، فكانت النتيجة صامتة. المحاولات التي يفشل فيها Edge تُحفظ للمراجعة ولا تنضاف إلى المعرض تلقائياً.
الصوت الآلي الطبيعي المجاني غير مضمون. تسجيلك هو الخيار المجاني الطبيعي؛ لا تستخدم خدمات مدفوعة تلقائياً.
فيديو المقال والمعرض الحالي بصوته الخليجي المعتمد محفوظ في almusaileem-images ولم يُستبدل بالاختبار الصامت.

## الحفظ والمجانية

كل تشغيل يُحفظ في published/<run-id>/ برابط ثابت. انتهاء Artifacts بعد يوم لا يحذف النسخة المنشورة.
لا اشتراكات أو مفاتيح خدمات مدفوعة. الصور الجديدة بالذكاء الاصطناعي غير مربوطة؛ استخدم صورك أو الصور الجاهزة.
التشغيل يدوي على ubuntu-24.04 القياسي، مهمة واحدة في كل مرة، وحد 20 دقيقة.
GitHub Actions يشغل الطلب ثم يتوقف؛ الموقع يعرض النتائج باستمرار، لكنه لا يستضيف مولد الفيديو 24 ساعة.
المستودع عام والوسائط المنشورة عامة. لا تضع تسجيلات أو صوراً خاصة في الروابط المستخدمة.

## التشغيل المحلي

Python 3.12 وFFmpeg. استنسخ https://github.com/harry0703/MoneyPrinterTurbo إلى engine عند commit bd6939b61292d2acf435e0c8bd442470843a2781، وثبت requirements.txt، ثم:

```bash
VOICE_MODE=silent python render.py
```

التحقق الأخير: نجح فحص Python واختبار إدخال النص، منع روابط الشبكة الخاصة، حفظ الوسائط، المحافظة على فهرس الفيديوهات، واستبعاد فشل الصوت من المعرض. تم التحقق من قراءة المعرض للفهرس وتحميل فيديو 15 ثانية بالموقع. لم يُعد اختبار إنتاج فيديو كامل بعد إضافة حقول الإدخال الجديدة.
