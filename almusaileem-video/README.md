# مصنع فيديوهات المسيليم المجاني

قالب MoneyPrinterTurbo: 3 صور، 15 ثانية، 1080×1920، خط تجوال.

## التشغيل على GitHub

1. الملفات موجودة في almusaileem-video، وملف التشغيل في .github/workflows/almusaileem-free-video.yml.
2. افتح Actions ثم Almusaileem free video ثم Run workflow.
3. اختر الصوت: edge صوت رجل كويتي مجاني؛ uploaded تسجيلك في assets/voice.wav؛ silent بدون صوت.
4. بعد اكتمال المهمة، حمّل الناتج من Artifacts. مدة الاحتفاظ يوم واحد، فاحفظ الفيديو عندك.

لتغيير المحتوى: بدّل الصور assets/01.jpg إلى 03.jpg، وعدّل النص والعناوين في config.json.
صور المثال مولّدة للتوضيح. اضبط illustrative=false فقط عند استعمال صور التنفيذ الحقيقية.
خدمة Edge قد ترفض الاتصال أو تتوقف. عند فشلها ينتج الفيديو صامتاً ويظهر السبب في report.json.
لم نستخدم صوت Piper الآلي الذي لم يعجبك. تسجيلك يعطي صوتاً طبيعياً بدون رسوم.

## المحافظة على المجانية

- لا اشتراكات ولا مفاتيح خدمات مدفوعة في الحزمة.
- توليد صور جديدة بالذكاء الاصطناعي غير مربوط؛ استخدم صورك أو الصور الموجودة.
- مهمة يدوية فقط، بدون جدول متكرر، ومهمة واحدة في كل مرة بحد 20 دقيقة.
- GitHub: تشغيل الأجهزة القياسية مجاني للمستودعات العامة؛ الخاصة تعتمد على الحصة المجانية لحسابك.
- قبل التشغيل في مستودع خاص، اضبط ميزانية Actions على صفر مع إيقاف الاستخدام عند الحد، وتحقق من حصتك والتخزين. الحزمة لا تغير إعدادات فوترتك.
- لا تحول مستودعاً خاصاً إلى عام لمجرد توفير التكلفة؛ الصور والملفات في المستودع العام تكون ظاهرة للآخرين.
- إذا انتهت الحصة أو لم تكن كافية: أوقف Actions وشغل محلياً، لا تشترِ موارد إضافية تلقائياً.

GitHub Actions يشغل كل طلب ثم يتوقف؛ هذه ليست واجهة ويب مستضافة 24 ساعة.
تم تركيب هذا القالب كمسار MoneyPrinterTurbo مستقل داخل مستودع OpenMontage. اختُبر محلياً؛ لم يُختبر التشغيل على أجهزة GitHub بعد.
